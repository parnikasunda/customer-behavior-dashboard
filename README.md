# Customer Behavior Dashboard

## Project Overview
This project analyzes customer shopping behavior using Python, SQL, and Tableau.  
The dashboard provides insights into customer purchasing trends, revenue distribution, subscription patterns, and sales performance across different categories and age groups.

The goal of this project is to perform end-to-end data analysis and create an interactive business intelligence dashboard for decision-making.

---

## Tech Stack
- Python (Pandas, NumPy, Matplotlib)
- SQL
- Tableau
- Jupyter Notebook

---

## Project Workflow
1. Data Cleaning and Exploration using Python
2. Business Query Analysis using SQL
3. Interactive Dashboard Creation in Tableau
4. Data Visualization and Insight Generation

---

## Features
- KPI Cards for:
  - Number of Customers
  - Average Purchase Amount
  - Average Review Rating

- Interactive Filters:
  - Gender
  - Category
  - Shipping Type
  - Subscription Status

- Visualizations:
  - Subscription Donut Chart
  - Revenue by Category
  - Sales by Category
  - Revenue by Age Group
  - Sales by Age Group

## Key Insights
- Clothing category generated the highest sales and revenue.
- Middle-aged customers contributed the highest overall revenue.
- Majority customers were non-subscribers.
- Customer purchasing behavior varied across product categories and age groups.
